# Meridian dashboard

Findings dashboard for the Meridian project — a historical replay of the March 2023
USDC and May 2022 UST depeg events, the rule-based risk score, and the ML crisis
classifier's results.

Reads static JSON from `data/`, generated by `../spark/export_dashboard_data.scala`.
It does **not** query Hive live — see `../CLAUDE.md` and `../ARCHITECTURE.md` for why
(measured Hive query latency, batch-only update model).

## Regenerating the data

After any pipeline update:

```bash
$SPARK_HOME/bin/spark-shell -i ../spark/export_dashboard_data.scala
```

This overwrites `data/*.json`. Restart the dev server (or rebuild) to pick up changes.
